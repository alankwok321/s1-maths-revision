# S1 Maths Exam Revision 中一數學考試溫習

Interactive revision guide for S1 Mathematics (Ch 1, 2, 3, 4, 6, 7, 8): animated lessons, unlimited practice questions, key points, a "Last 10 Minutes" summary and a mixed mock test. Bilingual (English / 中文).

- `index.html` – the built, self-contained site (deploy this).
- `src/` – source files. Rebuild with `python3 build.py` — writes `index.html`.
